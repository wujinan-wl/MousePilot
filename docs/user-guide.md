# MousePilot 使用說明

MousePilot 是純本機執行的 Windows 桌面小工具：閒置一段時間後自動微移滑鼠，避免筆電進入螢幕保護／待機；同時支援自訂 Windows 滑鼠游標圖案（匯入圖片、編輯 Hotspot、預覽、套用與安全恢復）。

## 1. 簡介與系統需求

- 支援 Windows 10 64-bit 與 Windows 11 64-bit。
- **免安裝**：`MousePilot.exe` 是單一 Portable 檔案，直接執行即可，不需要 Installer。
- **免系統管理員權限**：所有寫入動作（設定、Log、開機自啟）都只使用目前使用者的權限範圍。
- 執行期資料一律放在 `%AppData%\MousePilot\`，程式本身所在目錄不需要寫入權限，可放在隨身碟等唯讀位置執行。

## 2. 第一次啟動

- 第一次執行 `MousePilot.exe` 時，程式預設會直接縮到系統匣（工作列右下角通知區），不會跳出主視窗（對應「啟動後最小化至系統匣」設定，預設開啟）。
- 若找不到視窗，到系統匣圖示（綠色圓形滑鼠滾輪圖案）：
  - **雙擊**圖示即可開啟 Dashboard 主視窗；
  - 或**右鍵**圖示，於選單點「開啟 MousePilot」（或「設定」，兩者行為相同，都會開啟 Dashboard）。
- 若同時設定了「啟動程式後自動開始監控」（預設開啟），監控會在啟動當下自動開始，不需要另外按啟動。

## 3. Dashboard 導覽（狀態卡）

Dashboard 上方的「狀態」卡片會即時顯示：

- **狀態點顏色與文字**：
  - 灰色「已暫停」：尚未啟動監控。
  - 綠色「監控中」／「使用者活動中」：正在偵測閒置，或偵測到使用者正在操作。
  - 黃色「等待啟動」／「自動移動中」：即將觸發第一次移動，或正在執行一次自動移動。
  - **紅色「錯誤（滑鼠移動失敗）」**：滑鼠移動連續失敗達 3 次時進入此狀態，之後失敗只會靜默記錄到 Log、不再持續彈提示；只要下一次移動成功、或按「暫停」（錯誤狀態下「啟動」按鈕不可按——先暫停解除，再按「啟動」即可重新開始監控）、或重新啟動程式，就會解除紅點回到正常狀態。
- **閒置秒數**：目前使用者已閒置多少秒。
- **滑鼠座標**：目前滑鼠的螢幕座標（X、Y）。
- **距離第一次觸發**：距離第一次自動移動還剩多少秒（尚未進入倒數時顯示「—」）。
- **距離下一次移動**：距離下一次自動移動還剩多少秒。
- **游標**：目前游標狀態，顯示「Windows 預設」或「已套用自訂游標」。
- **觸發次數**：本次執行以來，自動移動已觸發的次數（不含「立即執行一次」）。

狀態卡下方有三個按鈕：「啟動 MousePilot」「暫停」「立即執行一次」。

## 4. 閒置偵測設定（自動移動設定卡）

| 欄位 | 意義 | 允許範圍 | 預設值 |
| --- | --- | --- | --- |
| 開始閒置（秒） | 使用者停止操作多久後開始自動移動 | 5 ～ 86400 | 120 |
| 後續移動間隔（秒） | 第一次觸發後，之後每隔多久再移動一次 | 1 ～ 86400 | 30 |
| 移動像素（px） | 每次微移的像素距離 | 1 ～ 100 | 3 |
| 移動模式 | 「左右移動」「上下移動」「隨機方向」三選一 | — | 隨機方向 |

另有「移動後回到原位置」勾選框（預設勾選）：勾選時，每次微移後約 300 毫秒會自動移回原本的座標；若在等待返回期間偵測到真實使用者操作（鍵盤輸入，或滑鼠已不在剛移到的座標），會立即放棄返回動作，不會硬把滑鼠拉回去。

**輸入超界的處理**：三個數值欄位若手動輸入超出上表範圍（例如把「開始閒置」改成 0 或 100000），欄位本身不會立即擋下輸入；但按下「啟動 MousePilot」時，程式會自動把數值夾制回合法範圍，並把欄位內容回填為夾制後的實際值。

## 5. 啟動 / 暫停 / 立即執行一次

三種途徑都可以控制監控狀態：

1. **Dashboard 按鈕**：「啟動 MousePilot」「暫停」「立即執行一次」。
2. **系統匣選單**：右鍵圖示選「啟動」「暫停」「立即執行一次」（選單項目會依目前狀態自動啟用/停用，例如已啟動時「啟動」會變灰）。
3. **全域快捷鍵**：預設 `Ctrl+Alt+F9` 切換「啟動 / 暫停」（在 Windows 任何地方按都有效，不需要 MousePilot 視窗在前景）。

「立即執行一次」不受閒置計時影響，會依目前的移動設定立即執行一次微移（含返回原位置，若有勾選）。

## 6. 系統匣

系統匣右鍵選單完整項目（由上到下）：

1. 開啟 MousePilot（開啟 Dashboard）
2. ── 分隔線 ──
3. 啟動
4. 暫停
5. 立即執行一次
6. ── 分隔線 ──
7. 啟用自訂游標（等同 Dashboard 的「套用」）
8. 停用自訂游標（等同 Dashboard 的「恢復 Windows 游標」）
9. 恢復 Windows 游標
10. ── 分隔線 ──
11. 設定（開啟 Dashboard，設定就在 Dashboard 上）
12. 結束

雙擊系統匣圖示等同點選「開啟 MousePilot」。

**關閉視窗＝縮到系統匣**是預設行為：直接按 Dashboard 右上角的關閉鈕（X）不會結束程式，只會把視窗隱藏回系統匣，監控繼續在背景執行。這個行為可由「系統設定」卡片中的「關閉視窗時最小化至系統匣」勾選框控制；若取消勾選，關閉視窗會直接結束整個程式（等同系統匣選單的「結束」）。真正要結束程式，一律使用系統匣選單的「結束」（或取消上述勾選後關閉視窗）。

## 7. 開機自動啟動

「系統設定」卡片的「Windows 開機時自動啟動」勾選框，會把設定寫入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（僅目前使用者的登入設定，不會寫入 HKLM，因此不需要系統管理員權限）。

- 勾選時：寫入登入啟動項，並自動清除工作管理員「停用」殘留的旗標，確保啟動項目真的生效。
- 取消勾選：移除登入啟動項。
- 每次啟動程式時，會自動與 Registry 現況同步：若已註冊，會用目前 EXE 路徑重新寫入一次（避免 EXE 檔案搬移後啟動項失效）。

**與工作管理員的互動**：如果使用者曾在工作管理員「啟動」分頁把 MousePilot 設為「已停用」，登入啟動項的值仍然存在，但工作管理員會標記為停用旗標，Windows 登入時不會真的執行；MousePilot 啟動時偵測到這個停用旗標，會把 Dashboard 上的勾選框顯示為「未勾選」（因為實際上不會自啟）。只要重新勾選一次，程式就會清除停用旗標並讓開機自啟重新生效。若寫入 Registry 失敗（例如權限被安全軟體攔截），會顯示提示訊息並把勾選框還原成失敗前的狀態。

## 8. 全域快捷鍵

「系統設定」卡片下方有兩組快捷鍵欄位：

- **啟動 / 暫停**：預設 `Ctrl+Alt+F9`。
- **恢復 Windows 游標**：預設 `Ctrl+Alt+F10`。

**錄製方式**：點擊欄位（欄位本身是唯讀，不能直接打字），然後按下想要的組合鍵，程式會攔截這次按鍵並嘗試設定為新的快捷鍵。

**設定檔格式嚴格區分大小寫**：快捷鍵在畫面上與 `settings.json` 中都是固定格式，例如 `Ctrl+Alt+F9`——修飾鍵固定為 `Ctrl` `Alt` `Shift` `Win`（字首大寫、其餘小寫），主鍵可為 `F1`～`F24`、`A`～`Z`、`0`～`9`，全部以 `+` 連接、至少一個修飾鍵加恰好一個主鍵。**若手動編輯 `settings.json` 把大小寫寫錯**（例如 `ctrl+alt+f9`），程式會判定該字串無效，對應的快捷鍵會直接**停用**（不會自動修正大小寫），並在 Log 記一筆錯誤、Dashboard 上也會出現提示。

**錯誤提示**：

- 若組合鍵已被其他程式占用（Win32 錯誤碼 1409），會提示「快捷鍵 ⟪組合⟫ 已被其他程式占用」，並自動還原成原本的組合鍵。
- 若與另一個 MousePilot 快捷鍵設定成同一組合（即使文字不同但實際按鍵相同），會提示「快捷鍵不可與另一項重複」。
- 若格式本身不合法，會提示格式要求（至少一個修飾鍵 + 一個主鍵）。

## 9. 自訂游標——完整流程

Dashboard 的「游標設定」卡片有五個按鈕：「選擇 / 編輯游標」「匯入圖片」「移除圖片」「套用」「恢復 Windows 游標」。

### 9.1 匯入圖片

點「匯入圖片」開啟檔案選擇對話框，**支援格式**：`.png` `.jpg` `.jpeg` `.bmp` `.cur` `.ani`。選定後檔案會被複製到 `%AppData%\MousePilot\Cursors\`（同名檔案會自動編號，不覆蓋既有檔案）；若圖片損毀或格式不支援，會顯示錯誤訊息且不留下殘檔。

### 9.2 游標編輯器（「選擇 / 編輯游標」）

編輯器視窗分為三欄：

- **左欄——來源選擇**：上方「我的收藏」（已加入收藏的圖案，快速存取），下方「全部圖案」是完整清單，包含 16 個內建圖案（8 個基本樣式 + 8 個可愛風格，含藍色機器貓造型）以及所有已匯入的檔案，以縮圖 + 檔名／圖案名稱呈現。
- **中欄——編輯區**：
  - 上方 256×256 預覽方框，點擊圖片可直接在圖上點選 Hotspot（滑鼠實際作用點）位置，畫面上會有十字標記。
  - 顯示「原始尺寸」與「實際使用」（最終輸出的游標尺寸）。
  - **尺寸**下拉選單：16／24／32／48／64／96／128 px 七種可選（`.cur`/`.ani` 原檔來源時此欄停用，因為原檔尺寸與 Hotspot 直接使用檔案內容，不參與處理）。
  - **Hotspot X / Y**：可用點擊圖片設定，也可以直接在欄位手動輸入數字；輸入值會自動夾制在 `0` 到「目前尺寸 - 1」之間。
  - **移除背景（JPG 建議）** 勾選框：僅圖片檔案（非 `.cur`/`.ani`）可用，勾選後啟用「容差」欄位（0～255），以圖片左上角像素當作參考色，容差內的像素會被去除為透明（去背）。
  - 若去背後畫面沒有任何可見內容（例如容差設太高把整張圖都去掉），會出現退化警告：「去背後沒有可見內容——請降低容差或關閉去背。」，此時不會產生可用的游標檔，需調整容差或取消勾選去背。
- **右欄——模擬預覽**：把滑鼠移到白底、深底兩個示範區塊（含範例按鈕、Checkbox、連結、可輸入文字框）即可即時試用游標樣式；**這個預覽只作用在這兩個示範區塊內，絕對不會動到 Windows 全域游標**，可以放心試用。下方也會顯示目前 Hotspot 座標。

編輯器底部有三個按鈕：

- **加入 / 移除收藏**：把目前選取的來源加入或移出「我的收藏」。
- **確定**：把目前編輯結果記錄為「已確認」設定並關閉編輯器，但**不會**立即套用到 Windows 全域游標（Dashboard 卡片會顯示已選擇的游標，但游標狀態仍維持原樣，需再按「套用」）。
- **套用**：等同先按「確定」，再立即執行一次「套用到 Windows」。

### 9.3 套用與確定 vs 套用

- Dashboard 上的「套用」按鈕，會把「確定」（或編輯器裡的「套用」）所記錄的游標檔實際套用到 Windows 系統游標；成功後 Dashboard 「游標」狀態會顯示「已套用自訂游標」，並跳出提示「已套用自訂游標。」
- 若套用失敗（例如游標檔案已損毀或被移除），會提示「套用游標失敗（檔案可能已損毀或被移除）。」，並確保不會誤留下「已套用」的假象狀態。

### 9.4 恢復 Windows 游標的四種途徑

1. Dashboard「游標設定」卡片的「恢復 Windows 游標」按鈕。
2. 系統匣選單「停用自訂游標」或「恢復 Windows 游標」（兩者行為相同）。
3. 全域快捷鍵（預設 `Ctrl+Alt+F10`）。
4. 命令列參數 `MousePilot.exe --restore-cursor`（詳見 `docs/debugging.md`；這是不受單一實例限制、專為緊急救援設計的獨立途徑）。

恢復動作一律透過 Windows 的 `SPI_SETCURSORS` 重新載入使用者原本的 Cursor Scheme，不是「記住並寫回」單一游標，因此不會破壞使用者原本的游標設定。

### 9.5 重開程式自動套回

若上次結束程式時游標處於「已套用自訂游標」狀態，下次啟動 MousePilot 時，只要確認檔案仍存在，會自動重新套用同一個游標，延續上次的視覺狀態，不需要每次重開都手動再套用一次。

## 10. 通知

MousePilot 有兩種通知管道：

- **視窗內 Notice**：Dashboard 最上方的黃色提示條，內容為空時整塊隱藏，出現訊息時會顯示（例如設定損毀提示、快捷鍵錯誤、游標套用失敗等）。
- **系統匣 balloon 通知**：當主視窗不可見（縮在系統匣）時，同樣的提示內容會改以 3 秒的 balloon 通知彈出，讓使用者即使沒開著 Dashboard 也能看到重要訊息。

**已知限制**：

1. 程式**啟動期間**（主視窗與相關元件建構中）若產生的通知，不會彈出 balloon（此時系統匣尚未完整掛上通知監聽），但仍會寫入 Log 供事後查閱。
2. **同一則文字內容的通知連續發生**時，只有第一次會彈出 balloon，重複的相同文字不會重複彈出（不同文字內容則會各自彈出）。

## 11. 設定檔與資料位置

所有執行期資料都存放在 `%AppData%\MousePilot\`：

| 路徑 | 用途 |
| --- | --- |
| `settings.json` | 所有使用者設定（閒置秒數、快捷鍵、游標設定等）。 |
| `Logs\mousepilot.log` | 目前的執行 Log，超過 5MB 會輪替歸檔。 |
| `Logs\mousepilot.1.log` ~ `mousepilot.3.log` | 歷史 Log 歸檔（最多保留 3 份，`.1` 為最新）。 |
| `Logs\mousepilot-bootstrap.log` | 啟動診斷 Log（v1.0.1 起）：記錄啟動各階段里程碑與啟動期例外的完整內容，排查「程式打不開/一開就閃退」時查看此檔。 |
| `Cursors\` | 使用者匯入的游標圖片/檔案儲存位置。 |
| `confirmed-cursor.cur` | 目前「確定」/「套用」所使用的最終游標檔（放在根目錄，不會出現在圖案清單中）。 |
| `cursor-applied.marker` | 內部狀態檔：存在代表「游標已套用但尚未正常恢復」，供程式異常結束後下次啟動自動補救。 |

`MousePilot.exe` 所在目錄不需要任何寫入權限，可放在唯讀媒體上執行。
