MousePilot 快速上手

防閒置滑鼠微移 × 自訂游標　·　免安裝、免系統管理員權限

三步開始使用

  1. 執行 MousePilot.exe免安裝，直接雙擊。程式預設縮在右下角系統匣（藍色圓形圖示），雙擊圖示打開主畫面。
  2. 設定「閒置幾秒後開始」預設 120 秒。也可調整移動間隔、移動像素與方向模式（左右／上下／隨機）。
  3. 按「啟動」狀態點轉為綠色即代表監控中——之後只要你放著不動超過設定秒數，MousePilot 就會輕輕動一下滑鼠防止待機，並自動移回原位。你一動滑鼠或鍵盤，它立刻讓路。
建議順手勾選「開機自動啟動」與「啟動後自動開始監控」——之後開機即自動守護，完全不用再操作。

看懂狀態點

顏色狀態意義
綠監控中／使用者活動中正常運作，等待閒置達標
黃等待啟動／自動移動中已達閒置門檻，依間隔執行微移
灰已暫停按「啟動」開始監控
紅錯誤（滑鼠移動失敗）連續失敗 3 次；按「暫停」解除後再「啟動」，或等下一次成功自動解除

自訂游標（五步）

  1. 打開編輯器主畫面「游標設定」卡 →「選擇 / 編輯游標」。
  2. 挑圖案左側 16 個內建圖案直接點；或先「匯入圖片」（支援 PNG／JPG／BMP／CUR／ANI）。常用的可「加入收藏」。
  3. 調整選尺寸（16~128）；點圖片任意處設定 Hotspot（實際點擊位置）；JPG 相片可勾「移除背景」。
  4. 試用滑鼠移進右側預覽區，游標立即變成你的圖案——這只影響預覽區，不會動到系統。
  5. 套用按「套用」全系統生效。想復原按「恢復 Windows 游標」、Ctrl+Alt+F10，或系統匣選單。程式關閉／當機／登出都會自動恢復，不會弄壞你的游標設定。

快捷鍵

組合鍵功能
Ctrl+Alt+F9啟動／暫停監控（可在設定卡自訂）
Ctrl+Alt+F10立即恢復 Windows 原始游標（可自訂）

疑難速查

游標卡在自訂圖案回不去？

重新啟動 MousePilot 會自動補救；或在「執行」（Win+R）輸入 MousePilot.exe --restore-cursor 立即恢復。

放著不動卻沒有觸發？

確認狀態點是綠色（已啟動）、閒置秒數確實已超過設定值，且期間完全沒碰滑鼠鍵盤。

再點一次 EXE 沒反應？

MousePilot 只允許一份執行——第二次啟動會自動把原本的主畫面叫出來，不會多開。

想看程式做了什麼？

記錄檔在 %AppData%\MousePilot\Logs\mousepilot.log；所有設定與游標檔都在 %AppData%\MousePilot\，移除程式只要刪 EXE 與這個資料夾。

程式打不開、一啟動就閃退？

請先確認下載的是 v1.0.1 或之後的版本（v1.0.0 在部分電腦會啟動即閃退，已修正）。仍有問題時，把 %AppData%\MousePilot\Logs\ 裡的 mousepilot.log 與 mousepilot-bootstrap.log 一併附上回報。
